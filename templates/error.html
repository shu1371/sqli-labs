关卡 2 · 报错注入 (Error-Based)

漏洞类型：字符型注入。参数 username 被单引号包裹后拼接。
目标：利用自定义函数 leak() 在报错信息中带出 flag 表的内容。
原理：当注入触发 leak(查询) 时，函数会抛出一个包含查询结果的异常，从而把数据回显到错误信息里。
执行的 SQL
{{ query }}
{% if error %}
错误信息（数据可能在这里泄露）
{{ error }}
{% endif %}
{% if rows %}
结果
{% for k in rows[0].keys() %}{% endfor %} {% for r in rows %}{% for v in r.values() %}{% endfor %}{% endfor %}
{{ k }}
{{ v }}
{% endif %}

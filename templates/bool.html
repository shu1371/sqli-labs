关卡 3 · 布尔盲注 (Boolean-Blind)

漏洞类型：字符型注入，参数 name 被 LIKE '%...%' 包裹。
特点：页面只返回 exists / not found，不回显任何数据列，需要逐位猜解。
目标：通过 true/false 的差异，逐字符猜出 flag 表的内容。
执行的 SQL
{{ query }}
{% if error %}
错误信息
{{ error }}
{% else %}
返回结果
{{ result }}
{% endif %}
示例 payload（判断 flag 首字符是否为 F）：
x' OR (SELECT substr(secret,1,1) FROM flag)='F' OR 'x'='
命中返回 exists，否则 not found，据此二分/逐位爆破。
